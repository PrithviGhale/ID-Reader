# AgeCheck 1.0.0

First release for Windows x64, with the .NET 10 runtime included.

- Native WPF interface with large results, short transitions and reduced-motion support.
- Local barcode age and expiration checks for a strict subset of AAMVA versions 08–10 (USA/CAN).
- Focus-only USB keyboard scan capture, full-frame validation and synthetic demos.
- Automatic clearing on focus loss, next scan and after 30 seconds.
- Stable GitHub updates through Velopack with explicit download and restart controls.

This release is unsigned. Physical Honeywell scanner compatibility and an installed-to-installed update have not yet been verified. Test your scanner configuration with synthetic data before operational use.
