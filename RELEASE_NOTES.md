# AgeCheck 1.7.1 - Faster return to scanning

- Returning to Scan from Home or another tab now moves keyboard focus off the navigation button, so the next scanner input can start immediately.
- Removed the large banner above the scan result to bring the card check higher on screen.
- Page changes now slide from the left or right according to the tab direction. The existing motion setting still disables these transitions.
- Shortened the issuing-state placeholder while waiting for a scan.

AgeCheck calculates age and expiration from barcode fields. It does not authenticate the physical ID or replace a comparison of the card, photograph and customer.
